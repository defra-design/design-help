# User need and context

## Why this app has been suggested

The Defra design team has moved to a management model where resource managers support line management. This has improved administration and the smooth running of core management responsibilities.

At the same time, it can leave a gap in design-focused support. Things like design critiques, design tooling help, and longer-term designer coaching are now more dependent on the design community supporting itself.

## The user need

Designers need a simple way to find and offer support to each other, without relying only on informal networks or existing personal contacts.

Managers also need a practical way to support this behaviour and make sure the support effort is visible and sustainable.

## Why this matters now

Our team has a lot of experience and knowledge to share. Much of that value can go untapped if people do not know who can help with what, or how to ask.

This tool is intended to prompt people to both find help and offer help across the design community.

## What this first version is for

This is a first iteration. We can keep it, adapt it, improve it, or stop using it based on feedback and evidence of what works.

The intent is that everyone takes an active role in supporting each other in our profession, from small practical help to longer-term development support.

Examples include:

- finding a file or piece of code
- getting feedback on an idea
- support with design tooling
- design critiques
- career planning and coaching

## What we ask from users

Think about two things:

- what you can offer
- what you would like help with
